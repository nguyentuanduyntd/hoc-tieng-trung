# Học Tiếng Trung

Web học tiếng Trung cho người Việt, bắt đầu từ HSK 1, có âm Hán Việt cho từng chữ. Chỉ có frontend; tiến độ lưu trên trình duyệt.

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # unit test
npm run data     # build lại dữ liệu từ vựng từ data/
npm run build    # data + typecheck + build ra dist/
```

Cần Node ≥ 22.18 (chạy trực tiếp script `.ts`). Đặc tả: `SPEC-hoc-tieng-trung.md`. Hiện trạng: `docs/CURRENT_STATE.md`. Nguồn dữ liệu: `docs/DATA_SOURCES.md`.
